# Notepad++ syntax highlighting

## Installation

1. Open Notepad++.
2. Select `Language > User Defined Language > Define your language`.
3. Select `Import`.
4. Import `lsq.xml`.
5. Open a `.lsq` file.
6. Select `Language > LSQ Script` if Notepad++ does not select it automatically.

The language definition highlights commands, control-flow statements, device methods, connection parameters, variables, strings, numbers, operators, and `#` comments.

The `.lsq` extension is declared by the language definition. If another installed language already claims `.lsq`, select `LSQ Script` manually from the Language menu.
