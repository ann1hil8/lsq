## Driver interface

Settings use `set_*` methods. Queries use `get_*` methods. The driver also exposes `set(command, ...)` and `get(command)` for every catalog entry.

## Error handling

A successful VISA write does not guarantee that the instrument accepted the value. Use `get_system_error()` after a write when the procedure requires explicit instrument error verification.
